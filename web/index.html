MRI TogetherThon setup

30 November – 4 December 2026. Every hands-on session runs in one ready-made environment on your own computer: JupyterLab with Python and Julia, and a shell. Set it up before 23 November and join an install session if anything fails.

1

Install Docker

You need macOS (Intel or Apple Silicon), Linux, or Windows 10/11 with WSL2, with 16 GB of memory recommended and about 40 GB of free disk.

  • macOS, Windows: Docker Desktop. On Windows choose the WSL2 backend; wsl --status in a terminal tells you whether WSL2 is on.
  • Linux: Docker Engine or Docker Desktop.
  • In Docker Desktop's Settings → Resources, give Docker at least 8 GB of memory.

Installing Docker needs administrator rights: on a managed computer, ask your IT department early. Docker Desktop is free for personal use, education and small organisations; employees of larger companies may need a paid subscription.

2

Run the launcher

Download the launcher for your computer and run it once. It downloads the environment (several GB, once), starts it, and opens JupyterLab.

Download the launcher Windows launcher

On macOS and Linux run it in a terminal with sh ~/Downloads/mritogetherthon.sh. On Windows double-click mritogetherthon.bat.

Your work lives in the mritogetherthon folder of your home folder, which is your home in JupyterLab: it stays on your computer through every restart and update.

3

Open JupyterLab

Looking for the environment on this computer…
Open JupyterLab

The button starts the environment, updates it when a newer one is published, and opens JupyterLab. Your browser asks once whether this page may open the launcher. If the button does nothing, run the launcher again.

Then open a terminal in JupyterLab and run check-setup. Everything should be ✅.

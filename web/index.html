MRI TogetherThon setup

30 November – 4 December 2026. Every hands-on session runs in one ready-made environment on your own computer: JupyterLab with Python and Julia, and a shell. Set it up before 23 November and join an install session if anything fails.

1

Install Docker Desktop

Windows 10 or 11 runs Docker in WSL2. Turn it on first: open PowerShell as administrator, run this, and restart the computer.

wsl --install

Then download Docker Desktop, install it with the WSL2 option, and start it once.

Docker Desktop for Windows Windows on Arm

Most computers need the first one; the second is for Arm laptops, such as those with a Snapdragon processor. Docker gets half of the computer's memory, which is enough with 16 GB.

2

Run the launcher

Download it and double-click it. It downloads the environment (several GB, once), starts it and opens JupyterLab.

Download the launcher

If Windows protects you from it, choose More info → Run anyway. Your work lives in %USERPROFILE%\mritogetherthon, which is your home in JupyterLab.

1

Install Docker Desktop

Download Docker Desktop for your Mac's processor, drag it into Applications, and start it once.

Apple Silicon (M1 or newer) Intel

Or, with Homebrew:

brew install --cask docker-desktop

Apple menu → About This Mac names your processor. In Docker Desktop's Settings → Resources, give Docker at least 8 GB of memory.

2

Run the launcher

In Terminal, run this. It downloads the launcher and runs it, which downloads the environment (several GB, once), starts it and opens JupyterLab.

Your work lives in ~/mritogetherthon, which is your home in JupyterLab.

1

Install Docker

Install Docker Engine with your distribution's package manager:

Ubuntu, Debian, Linux Mint, Pop!_OS

sudo apt-get update && sudo apt-get install -y docker.io curl

Fedora. On RHEL, Rocky or AlmaLinux, follow Docker's instructions instead.

sudo dnf install -y moby-engine curl

openSUSE Leap and Tumbleweed

sudo zypper install -y docker curl

Arch Linux, Manjaro, EndeavourOS

sudo pacman -S --needed docker curl

Then start Docker, and let your user run it without sudo:

sudo systemctl enable --now docker && sudo usermod -aG docker $USER

Log out and in again for the second part to take effect. Docker Desktop for Linux works too.

2

Run the launcher

In a terminal, run this. It downloads the launcher and runs it, which downloads the environment (several GB, once), starts it and opens JupyterLab.

Your work lives in ~/mritogetherthon, which is your home in JupyterLab.

You need about 40 GB of free disk, and 16 GB of memory is recommended. Installing Docker needs administrator rights: on a managed computer, ask your IT department early. Docker Desktop is free for personal use, education and small organisations; employees of larger companies may need a paid subscription.

Then open a terminal in JupyterLab and run check-setup. Everything should be ✅.

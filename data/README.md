# Data

The files the hands-on sessions start from, which the organisers add before the
TogetherThon.

- [`phantoms/`](phantoms): the placenta phantoms of the simulation session, in
  increasing complexity: static with uniform B0; static with B0
  inhomogeneities in the surrounding tissue; with blood flow as well; with
  respiratory motion of the whole phantom as well.

Keep large files out of git: publish them, for example on Zenodo, and add here
the small script that downloads them.

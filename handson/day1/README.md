# Day 1: sequence

The notebooks of the day's hands-on go here, with whatever files they need.
The stage's contract is [`stages/sequence`](https://github.com/mcencini/mritogetherthon-pipeline/tree/main/stages/sequence).

- `pulseq/`: program a diffusion-weighted spin-echo EPI with pypulseq, in three
  levels, check it, and simulate it with MRzero. The speakers' repository, at
  the commit its [`SOURCE.md`](pulseq/SOURCE.md) names.
- `placenta_b_optimisation.ipynb`: simulate placenta diffusion signals, and
  optimise the protocol's b-values with machine learning.
